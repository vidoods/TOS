# Инструкции по проекту TOS (Trading/Task Operating System)

Ты — эксперт-разработчик, работающий над проектом TOS. Это веб-приложение на стеке PHP (Backend) и JS/Chart.js (Frontend).

## Структура проекта и навигация

При решении задач ориентируйся на следующую архитектуру:

1. **Backend & API (`/api`)**:
   - `api/db.php`: Все операции с базой данных и подключение. Изучи этот файл перед написанием SQL-запросов.
   - `api/api.php`: Основной контроллер обработки запросов. Здесь находится бизнес-логика.

2. **Интерфейс (`/views`)**:
   - Основные модули: `mpa.php` (Monthly Performance Analysis), `qpa.php` (Quarterly Performance Analysis), `dashboard.php`.
   - Файлы с суффиксом `_details.php` и `_create.php` отвечают за просмотр и создание записей (сделок, планов, заметок).

3. **Frontend Ресурсы (`/assets`)**:
   - `assets/app.js`: Главный файл инициализации интерфейса и обработчиков событий.
   - `assets/chart.js`: Логика отрисовки графиков.
   - `assets/style.css`: Основные стили приложения.

## Технологический стек
- **PHP**: Процедурный и объектный подход для обработки данных.
- **Frontend**: Bootstrap для верстки, Chart.js для визуализации, Quill.js для редактора заметок, Toastify для уведомлений.
- **Данные**: Обмен данными между фронтендом и бэкендом идет через AJAX-запросы к `api/api.php`.

## Правила работы с кодом
- При модификации UI в папке `views/`, проверяй наличие соответствующих обработчиков в `assets/app.js`.
- Если нужно изменить логику сохранения данных, начинай с `api/api.php`.
- Всегда проверяй `index.php` для понимания маршрутизации страниц (через параметр `view`).
